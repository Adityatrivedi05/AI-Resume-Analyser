# 📄 AI Resume Analyzer

An NLP-powered resume analysis tool that compares a candidate's resume with a job description and provides a compatibility score, skill analysis, and actionable feedback.

## 🚀 Features

- 📄 PDF resume parsing
- 🎯 Resume-job compatibility score
- 🛠️ Technical skill extraction
- ✅ Matching skill detection
- ❌ Missing skill detection
- 🔑 Job keyword extraction
- 💡 Resume improvement suggestions
- 📊 TF-IDF based text similarity

## 🧠 How It Works

Resume PDF
↓
Text Extraction
↓
NLP Processing
↓
Skill Extraction
↓
TF-IDF Vectorization
↓
Cosine Similarity
↓
Match Score
↓
Resume Feedback

## 🛠️ Tech Stack

- Python
- Streamlit

- NLP
- TF-IDF
- Cosine Similarity
